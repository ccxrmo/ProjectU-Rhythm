# ProjectU-Rhythm
> [!NOTE]
> This is a solo work in progress project. Don't expect huge improvements anytime soon

## Overview
I'm a begginner at coding and I wanted to started to move on to simple C++ programs and HTML to something a bit more substantial. So... here we are! I present to you **ProjectU-Rhythm** (this is just a codename, the real name for the game doesn't really exist).
### What exactly is this?
This project is actually a **Game** for Wii U! Precisely a **Rhythm** game. The concept of this game is similar to Dance Dance Revolution or Friday Night Funkin, you hit arrows at the beat of the song. 
### What's the current situation?
The project just started. It's not available. There isn't a build that you can download yet. But you can check the [U-Rhythm Development Progress](https://github.com/users/ccxrmo/projects/1) for the development status of the game or you can check the **Guide**/**Concept Idea** of the game that you can find inside this same repository.
